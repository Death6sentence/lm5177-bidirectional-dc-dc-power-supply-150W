# 机械外壳

此目录包含外壳模型及其配套的材质和纹理资产：

- `LM5177外壳.step`：可编辑的 CAD 交换模型
- `LM5177外壳.obj`：三角网格
- `LM5177外壳.mtl`：OBJ 材质定义
- `LM5177外壳.png`：材质纹理
- `lm5177-enclosure-preview.png`：由 `LM5177外壳.png` 裁剪得到的文档预览图

![LM5177 电源外壳三维示意图：双开口顶盖、内部隔板和底部安装孔](lm5177-enclosure-preview.png)

LM5177 电源外壳示意，图中可见双开口顶盖、内部隔板和底部安装孔。预览图及机械源资产均依据 CERN-OHL-S-2.0 授权。

STEP 文件是机械修改的首选源文件。使用渲染网格时，请将 OBJ、MTL 和 PNG 文件放在一起。
